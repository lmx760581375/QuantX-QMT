# QuantX 实验档案

> 建档日期：2026-07-13
>
> 目的：把策略研究过程、失败实验和证据边界长期保存在仓库中。
>
> 重要说明：这里记录的是研究证据，不是实盘收益承诺。

## 1. 为什么单独建立这个目录

QuantX 已经完成过规则策略、ETF 轮动、机器学习模型、市场状态模型和组合稳健性等多类实验。此前详细结果一部分在 `docs/development`，另一部分只存在于临时研究目录。当前约定新实验统一放在项目根目录 `.tmp/quantx-research/`。如果只保留最终高收益数字，会丢失以下重要信息：

1. 当时使用了什么数据和股票池。
2. 信号时间和交易时间是否严格隔离。
3. 哪些结果只是随机 300 只股票的方向筛选，哪些已经扩展到全市场。
4. 哪些参数是在反复查看 2021-2025 后选出的，不能再把该区间当成最终测试集。
5. 哪些想法已经验证失败，不应该反复重新尝试。
6. 哪些结果还缺多随机种子、双倍成本或 2026 前向检验。

本目录以后作为实验的入口。实验配置和大型运行产物仍按约定先留在项目根目录 `.tmp/quantx-research/`，确认值得保留后再进入正式策略库；但实验问题、方法、结果和结论必须写入这里。

## 2. 状态定义

| 状态 | 含义 |
| --- | --- |
| `plumbing_only` | 只证明框架能训练、产出预测并接入回测，不证明策略有效 |
| `screening_only` | 小样本或较弱口径的方向筛选，不能作为全市场结论 |
| `development_oos` | 严格按时间切分的样本外结果，但该区间已被反复用于研究选择 |
| `forward_check` | 在主要开发完成后追加的新时间区间检验，证据强于 development OOS |
| `retained_candidate` | 多项证据方向一致，值得继续补证，但尚未进入正式策略库 |
| `quarantined_pending_tradability_replay` | 历史结果有信息价值，但尚未通过统一可交易性污染审计和完整 QuantX 回测，不能作为候选或硬基线 |
| `rejected` | 当前实现没有改善目标指标，不继续投入，除非出现新证据 |
| `partial` | 实验只完成一部分，不能引用为最终结论 |
| `promoted` | 满足预先规定的全部晋级门槛并进入策略库；当前 ML 实验没有此状态 |

## 5. 当前最重要的结论

### 5.1 还没有可合代码的高收益候选

2026-07-15 审计更新：Exp40 `path_sequence_ranker_v1` 的“无未来函数”审计仍成立，但它不再被视为可复用强基线。原因是后续 Top7 bridge 接入主线时，用户点名的 `SZ000506`、`SZ000609` 等交易暴露了旧实验递归中的可交易性缺口：ST/退市票、停牌或零成交占位 bar、一字涨停买不到、卖出后反复回补等情况没有在实验准入阶段前置处理。补齐不可交易、一字板、-10% 止损、当前 ST/退市名称过滤、历史 5% 限幅 ST-like proxy 和卖出冷却后，主线 Top7 bridge 最终复核为 2022-01-04 至 2026-07-15 `+164.39%`，年化 `+23.95%`，最大回撤 `-39.69%`，Sharpe `0.822`；独立审计中点名坏交易、当前 ST/退市、缺失行情、零成交/零金额、一字涨停有效买入均为 0。普通高开不是统一不可交易污染，后续只作为诊断/分层分析；只有策略显式声明“不追高开”时，才把对应阈值作为该策略自己的执行约束。因此 Exp40 旧收益只能保留为“路径特征有信息”的诊断证据，不能作为 retained candidate、硬基线或合代码依据，直到用同一套递归可交易 gate 重跑 Top20/Top7 全口径。

2026-07-14 审计更新：Exp93 `formal_exit_lifecycle_policy_v1` 原本给出 head-union h6 生命周期控制 2021-2025 为 25.88x、2026 val63 为 `+35.64%` 的强结果，但复核发现脚本在当天 OPEN 退出判断前调用了当天 CLOSE 的账户更新，导致止损、续持和 trailing exit 使用了不可见信息。

把退出判断改为只使用上一交易日收盘后状态后，同一 head-union h6 `winner_extend max7` 降为：2021-2025 `8.07x`、最大回撤 `-28.07%`、逐年仍正；2026 val63 为 `+10.85%`、最大回撤 `-17.42%`。因此它不再是待集成候选，状态改为 `rejected_after_lookahead_audit`。

当前仍需寻找新的鲁棒高收益方向。任何后续候选进入正式代码前，仍需证明以下条件：

1. 足够长且覆盖多个市场阶段的严格样本外验证。
2. 不依赖事后知道的年度市场风格。
3. 最差年度和滚动 12 个月结果可接受。
4. 正常成本和双倍成本下都保持合理表现。
5. 平均股票持仓数量大于 5。
6. 2026 新区间中 Alpha 袖套本身仍有明显贡献。
7. 历史股票池具备退市、ST、停牌和历史成分 point-in-time 信息。

从 2026-07-15 起，递归实验还必须满足一个前置 hard gate：任何 label 层、简化账户或候选生成实验，如果没有显式输出可交易性污染审计，只能标记为 `diagnostic_only` 或 `quarantined_pending_tradability_replay`，不能标记为 `retained_candidate`。审计至少包括：有效买入中当前 ST/退市名称命中数、历史 ST-like proxy 命中数、缺失行情数、零成交量/零成交额数、一字涨停数、普通高开分布、点名坏交易回归检查、拒单原因分布、平均持仓数量和单票重复买入集中度。普通高开只作为诊断，不是统一 hard gate；若某个策略显式启用高开阈值，才额外记录“超过策略阈值”的拒单和收益影响。若无法取得 point-in-time 历史 ST 名称，必须明确披露并使用无未来函数的 5% 限幅代理；不得用当前 ST 名称倒灌过滤历史回测。

因此，本文档不使用“已找到”“保证盈利”等措辞。当前最重要的下一步是继续寻找新的可成交右尾土壤或低相关 sleeve，并把 Exp93 的教训前置到所有退出/止损/续持实验：OPEN 成交只能使用上一收盘前已知信息；若使用当日收盘状态，成交时点必须后移。

### 5.2 目前最有价值的发现是延长训练历史

2016 起训的 seed 7 Top20+五福逐年收益为：

```text
11.12%, -5.03%, +14.46%, +110.73%, +58.49%
```

把同一模型和同一组合规则的训练起点扩到 2010 后，seed 7 逐年变为：

```text
+31.81%, +14.90%, +31.21%, +63.36%, +47.77%
```

三 seed 集成后逐年为 `+31.41%、+13.43%、+29.45%、+62.71%、+46.59%`，年度收益标准差为 `16.71%`。标准成本累计 `+360.26%`、最大回撤 `-8.42%`；双倍成本累计 `+256.56%`、最大回撤 `-8.58%`。最差滚动 252 交易日收益在标准成本下为 `+5.25%`，双倍成本下为 `+0.78%`。这比牛熊专家、市场状态 gate 和多周期融合的改善更明确，说明短历史覆盖的市场结构不足可能是原模型收益集中度的重要来源。

但 2026 三 seed 的日均 RankIC 只有 `0.04304` 至 `0.04497`，线性 IC 和五分位 Top-Bottom 都为负。三 seed 组合为 `+6.84%`，其中 ML 80% 袖套为 `-0.25%`，五福 20% 袖套为 `+6.60%`。长历史没有修复 2026 Alpha 衰减，所以还不能宣布成功。

### 5.3 Learning 不等于自动学习牛熊

当前 LightGBM 的标签是未来 10 日个股相对全市场的超额收益。它优化的是横截面排序，不是指数涨跌、年度收益、最大回撤或牛熊识别。年度 RankIC 稳定而组合年度收益不稳定并不矛盾，原因包括：

1. 每年的横截面收益机会不同。
2. Top20 是排序尾部的非线性截断，平均 RankIC 提升不保证 Top20 提升。
3. 股票风险开关、五福袖套和交易成本共同影响净值。
4. 年度模型在年初冻结，当前训练流程对最近一年数据利用不足。
