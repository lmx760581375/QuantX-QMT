# 静态双 sleeve：Reward H15 + 弱转强（历史基线）

> 本组合已被 WTS65/RM35 季度现金再平衡双 sleeve 替代。

## 定义

最终组合不是同一个 5 仓账户内让两个策略抢仓位，而是两个独立子账户：

```text
初始资金
 ├─ 50% -> Reward H15
 └─ 50% -> 弱转强
```

之后：

- 不再平衡；
- 不共享现金；
- Reward 不替换弱转强；
- 弱转强不替换 Reward；
- 各自保留原始退出规则和交易成本。

这意味着它是净值层的静态组合，而不是一个新的单账户选股模型。

## 为什么不做共享五仓位

已验证三种“弱转强优先、Reward 补位”的单账户方案：

| 方案 | 总收益 | 年化 | 最大回撤 | Sharpe |
| --- | ---: | ---: | ---: | ---: |
| F0：满仓时跳过新弱转强 | 84.91% | 10.05% | -40.76% | 0.349 |
| F1：卖掉亏损 Reward 给弱转强 | 137.09% | 14.39% | -55.44% | 0.455 |
| F2：卖掉最差 Reward 给弱转强 | 128.61% | 13.75% | -58.42% | 0.379 |

F0 中累计有 1,837 个弱转强候选因 Reward 补满仓位而被跳过；F1/F2 虽增加弱转强占仓，却破坏 Reward 的持有路径并使回撤恶化。因此共享仓位模型被拒绝。

## 互补证据

2020-01-02 至 2026-06-02：

| 项目 | 值 |
| --- | ---: |
| Reward H15 日收益与弱转强日收益相关性 | 约 0.295 |

| 弱转强总收益 / 最大回撤 / Sharpe | 519.96% / -33.99% / 1.004 |
| 静态 50/50 总收益 / 最大回撤 / Sharpe | 446.95% / -23.91% / 1.194 |

静态组合的收益不高于最强单 sleeve 的最终收益是正常的；价值在于两条路径的回撤错位，使最大回撤明显下降、Sharpe 上升，净值斜率更连续。

## 图表与口径

`quantx-reward reproduce` 输出：

1. Reward、弱转强、组合累计收益曲线；
2. 组合回撤曲线；
3. 年 × 月收益热力图，红色为正、绿色为负；
4. 12 个自然月的历史收红概率图，例如“历年 2 月有 6/7 次收红”。

“月度胜率”在本项目中固定定义为**组合当月收益为正的比例**，不是平仓交易笔数胜率。
