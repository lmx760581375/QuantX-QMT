可以。最稳妥的方向不是替代 Transformer，而是把它从静态映射器改造成“参数化的预测动力学骨干”：

```text
历史 observation
      |
Transformer encoder -> z_t
      |
由 (s_{t-1}, p_{t-1}) 预测 z_t
      |
prediction error e_t
   /                 \
快速修正 s_t       中速更新 p_t
belief/state        fast memory / adapter
   \                 /
    产生当前输出，并预测下一 observation
              |
      慢速训练 / consolidation θ
```

我会把它定义为一个 `Predictive-Plastic Transformer`，核心状态为：

\[
z_t=E_\theta(x_t),\quad \hat z_t=P_\theta(s_{t-1},p_{t-1})
\]

\[
e_t=z_t-\hat z_t
\]

\[
s_t=s_{t-1}+\alpha_t U_\theta(s_{t-1},z_t,e_t,p_{t-1})
\]

\[
p_t=\rho_t p_{t-1}+\beta_t G_\theta(s_t,e_t)
\]

其中：

- `s`：少量可写的 belief slots，类似 Transformer memory token，但会被预测误差显式修正。
- `p`：会衰减、可重置的快速记忆。第一版建议做成低秩 adapter 或 key-value fast memory，不要直接改动全部 Transformer 权重。
- `θ`：普通 Transformer 参数，仍通过离线训练、回放或低频 consolidation 更新。

关键点是：`e_t` 同时驱动“我现在相信什么”（`s`）和“我这段时间该适应什么”（`p`），而不是只在训练时交给外部 optimizer。

这和现有路线的关系大致是：

| 已有方向 | 缺少的部分 |
|---|---|
| Transformer KV cache / recurrent Transformer | 有状态，但状态通常不由显式预测误差校正 |
| predictive coding / world model | 有预测误差和 latent state，但未必能自然扩展到 Transformer 与在线适应 |
| fast weights / Hebbian plasticity | 有快速适应，但常缺少统一的 belief inference |
| test-time training / adaptation | 会在线更新，但通常仍是外部梯度优化，且缺少多时间尺度统一机制 |
| continual learning | 关注长期记忆，却较少把即时推理与可塑性耦合 |

真正可能构成新架构的，不是单独提出 `state + plasticity + parameter`，而是证明这三者由同一个预测误差信号耦合后，能在非平稳环境中优于“长上下文 Transformer”或“测试时微调”。

第一版建议刻意收敛，避免一次性做成过度复杂的神经系统：

1. 保留现有 Transformer backbone。
2. 在输入前加入少量 persistent state tokens，例如 8 到 32 个。
3. 让模型预测下一 chunk 的 hidden representation，而不是直接预测原始 token；这样 prediction error 更稳定。
4. 根据 error 更新 state tokens。
5. 只在顶层一两个 block 加一个低秩 fast adapter 或外部 associative memory，作为 `p`。
6. `θ` 在 episode 之间训练，运行时先不直接更新基础权重。

这样可以先验证最关键的假设：显式的 belief correction 和短期 plasticity，是否比单纯 KV cache 更快适应规则变化。

一个很重要的因果约束是：预测误差必须来自当时真实可见的 observation。正确时间顺序应是：

\[
(s_{t-1},p_{t-1}) \rightarrow \hat z_t \rightarrow x_t \rightarrow e_t
\rightarrow (s_t,p_t) \rightarrow \hat z_{t+1}
\]

不能先看到了 `x_t`，再用它的误差去宣称提升了对 `x_t` 的预测。对流式文本、视频、传感器、交易序列尤其自然；对金融时序也很契合：模型预测下一时段状态，真实行情到来后修正市场 regime belief，并决定下一时段的策略。

研究上建议先用“隐藏规则会切换”的流式任务证明机制，再上真实数据。评价不只看最终准确率，还要看：

- regime 切换后的适应速度；
- 重复出现旧 regime 时的恢复速度；
- 长期遗忘程度；
- 相同参数、上下文长度与计算预算下的表现；
- `s`、`p`、`θ` 三个时间尺度分别移除后的消融结果。

第一阶段甚至可以允许 `s` 通过预测损失做 1 到 3 步内部梯度更新，作为概念验证；后续再把它蒸馏成前向的 learned update rule。这样既保留“模型内部优化”的本质，也不会一开始就陷入生物可解释性与工程可训练性之间的冲突。

下一步最值得先确定的是首个落地场景：流式语言、金融时序、视频/传感器，还是持续学习分类。不同场景决定 `observation`、`prediction error` 和 `plasticity` 应该如何定义。

## Codex — 2026-07-25T05:37:20.675Z

可以运行，但前提是不要一开始做“每个 token 都修改全模型参数”的自治系统。更可靠的形态是：**标准 Transformer 保持为稳定骨干，外接一个有界、可复位、可旁路的动力学控制器。** 动态机制失效时，模型应自动退化为原始 Transformer。

**推荐的最小架构**

```text
causal Transformer backbone θ
        │
  observation embedding h_t
        │
  prior state s_{t-1} ──> predict h_t ──> error e_t
        │                                  │
        └──────── state controller ◄──────┘
                         │
                    belief state s_t
                         │
              gated fast memory p_t
                         │
         residual injection into output block
```

建议先让 `p` 是固定容量的 fast memory，而不是直接修改 LoRA 或全模型权重：

\[
h_t=B_\theta(x_t),\quad \hat h_t=Q_\theta(s_{t-1})
\]

\[
e_t=\operatorname{clip}(\operatorname{Norm}(h_t-\hat h_t))
\]

\[
s_t=(1-g_t)s_{t-1}+g_t\tilde{s}_t,\quad 0\le g_t\le g_{\max}
\]

\[
p_t=\rho p_{t-1}+w_t\operatorname{write}(s_t,e_t)
\]

\[
y_t=D_\theta(h_t)+\gamma_t R_\theta(h_t,p_t)
\]

其中 `g_t`、`w_t`、`\gamma_t` 都应是有界门控；`p` 有固定容量、衰减和淘汰策略。这样状态不会无限漂移，短期记忆也不会无限累积。

**高效的关键约束**

- `s` 只保留 8 到 32 个 latent slots，不复制整段 KV cache。
- 按 chunk 更新，例如每 16/32 个 token、每根 K 线或每个传感器窗口更新一次，而不是每层每 token 更新。
- state controller 用一次 cross-attention 或小型 GRU/MLP，不参与完整 Transformer 的全层重算。
- `p` 先实现为固定大小的 key-value / associative memory；验证有效后再升级为低秩 fast adapter。
- 动态信息只注入顶层一个或两个 block，且残差系数从接近零开始学习。
- 内循环默认只做 1 次状态更新；只有高置信度的异常误差才允许最多 2 到 3 次 refinement。

这样动态部分的额外成本接近 `O(m · n · d)`，其中 `m` 是少量 state slots，而不会把 Transformer 的主成本扩大成全层循环。

**可靠性的四条硬规则**

1. `θ` 不在在线推理路径直接更新。
   `s` 是当前认知，`p` 是会话/任务适应，`θ` 只在验证过的 episode 后通过回放或离线训练 consolidation。

2. prediction error 必须因果可得。
   应该先用旧状态预测 `h_t`，观察到 `x_t` 后才能计算 `e_t` 并更新下一状态。不能让当前 observation 泄漏进当前预测。

3. surprise 不等于应该学习。
   写入 `p` 的门控应同时看误差、预测置信度、数据质量和已有记忆相似度。异常值、噪声和低置信度 observation 应被忽略或弱写入。

4. 永远可回退。
   每个 session 的 `s,p` 都可 reset；`p` 需要范数限制、TTL、写入预算和快照回滚；动态分支关闭后结果应等于基线 Transformer。

**训练方式**

外部 backprop 在第一阶段仍然保留，但它的职责变成“训练内部更新规则”，而非在线替模型做思考。训练目标可以是：

\[
L=L_{\text{task}}+\lambda L_{\text{prediction}}
+\mu L_{\text{stability}}+\nu L_{\text{write-budget}}
\]

其中 `L_stability` 惩罚状态/记忆的无意义抖动，`L_write-budget` 防止模型把所有 observation 都写入 fast memory。训练采用 episode 化的非平稳数据，并用 truncated BPTT 限制展开长度。

**建议的研发顺序**

1. 先做 `Transformer + belief state`，只验证 prediction-error state correction。
2. 再加入固定容量 fast memory，验证 regime shift 后的适应速度。
3. 最后才尝试 error-gated low-rank adapter 和慢速参数 consolidation。
4. 每一步都和同参数量的普通 Transformer、长 KV cache、recurrent Transformer、test-time adaptation 对比。

首个验证任务最好是有自然时间顺序和规则切换的流式问题。金融时序很适合这个机制：模型预测下一时段表征，真实行情到达后更新 market-regime belief，再影响下一时段决策；但理论验证最好先用可控的隐藏 regime 合成任务，避免市场噪声掩盖架构本身的效果。

下一步应先固定 `p` 的定义：我建议第一版用“有衰减、有限容量、误差门控的 fast key-value memory”，而不是在线改权重。这样开发量最小、稳定性最好，也最容易证明这套范式是否真的带来增益。

## Codex — 2026-07-25T05:42:35.360Z

有，而且这比只在模型顶层放一个全局 predictor 更有潜力。关键是不要让每个 block 变成互相独立、不断改权重的小系统，而应做成：

**每层有局部 JEPA-like predictor，但所有层的 error 由共享的状态控制器统一解释和调度。**

可以叫它 `Layerwise Predictive Transformer`。

对第 \(\ell\) 个 block，在时刻 \(t\)：

\[
q_{\ell,t}=\operatorname{Proj}_\ell(\operatorname{sg}[\bar h_{\ell,t}])
\]

\[
\hat q_{\ell,t}=P_\phi(a_\ell,s_{t-1},c_{\ell,t})
\]

\[
e_{\ell,t}=\operatorname{Norm}(q_{\ell,t}-\hat q_{\ell,t})
\]

其中：

- \(q_{\ell,t}\)：该层实际观察到的 latent target；
- \(\bar h\)：EMA 或 stop-gradient target branch，避免 predictor 和 target 一起坍塌；
- \(a_\ell\)：layer embedding，让共享 predictor 知道自己位于哪一层；
- \(c_{\ell,t}\)：过去 chunk 或可见部分的上下文；
- \(s_{t-1}\)：全局 belief state。

然后聚合各层误差：

\[
E_t=\sum_{\ell=1}^{L}\alpha_{\ell,t}\operatorname{Proj}(e_{\ell,t})
\]

\[
s_t=U(s_{t-1},E_t),\qquad
p_t=\operatorname{Write}(p_{t-1},s_t,E_t)
\]

这里的 \(\alpha_{\ell,t}\) 不是固定平均，而应由置信度、层级和异常程度共同决定。低层 error 更像感知异常，中层更像模式/结构变化，高层更像语义或任务假设错误。

最重要的因果事实是：**当前 block 得到 error 后，不能免费回头修正自身已经完成的计算。** 要用当前 error 改善同一 block 的输出，需要第二次执行该 block 或完整的反馈迭代，成本会快速失控。

因此第一版建议采用单向、高效路径：

```text
block l 产生 prediction error
        ├─ 修正全局 state，用于下一 chunk
        ├─ 写入 fast memory
        └─ 通过有界 residual，影响当前的更高层 block
```

也就是说，当前层的 error 可以改善后续层和未来时刻，但不立刻反复重跑自己。只有当全局 error 很高时，才条件触发一次“上半部分 block 的 refinement pass”。

实现上不建议真的给 24/32 个 Transformer block 各自配完整 JEPA 网络。更好的最小版本是：

- 只选 4 个代表层，例如 \(1/4, 1/2, 3/4, L\)；
- 每层只预测压缩后的 chunk summary，而不是每个 token 的完整 hidden state；
- predictor 共享主体参数，只保留 layer-specific projection 和 layer embedding；
- predictor 维度设为 backbone hidden size 的 \(1/8\) 到 \(1/4\)；
- 每个 chunk 更新一次 state，而不是每 token 更新；
- 每层只输出 error，不直接拥有长期 plasticity；只有共享 controller 有权写入 `p`。

这样每层都有“预测-误差”机制，但不会形成几十个耦合的、不稳定的小 optimizer。

JEPA 的关键约束也必须保留：predictor 和 target 不能看到同一份完整信息，否则它只是在复制当前 block。合理目标包括：

- 流式数据：预测下一 chunk 的 layer representation；
- 视频/时序：预测未来 frame 或未来 window 的 latent；
- 文本：预测下一段或被遮蔽区域的 latent，而不是直接预测自己的当前输出；
- 静态图像：用可见 patch 预测 masked patch 的 target embedding。

对于金融时序，这个结构很自然：各层分别形成价格局部形态、中期结构和高层 regime 的预测；真实下一窗口到来后，各层 error 汇入 state controller，更新市场 belief 与短期 memory。

可靠性上要加四个约束：

- 每层 error 独立归一化、截断，避免某一层数值支配全局状态；
- error 先经过 learned gate，再影响 state 或 memory，不能直接加回 hidden state；
- `s`、`p` 都有范数限制、衰减、固定容量和 reset；
- 动态分支残差从零初始化，关闭后严格退化为普通 Transformer。

我会建议先验证“4 个预测层 + 一个共享 state controller + 一个 fast memory”的版本。它已经足以验证你的核心命题：多层 prediction error 是否能形成比 KV cache 更有用、更稳定的 belief dynamics；确认有效后，再扩展到每个 block 都有 predictor。

最直接的第一条是 fixed-point theorem。把一次 iteration 写成：

\[
(S^{k+1},P^{k+1})=T_x(S^k,P^k)
\]

若能约束：

\[
\|T_x(u)-T_x(v)\|\le \rho\|u-v\|,
\qquad 0<\rho<1
\]

那么 Banach 不动点定理直接给出：

- 对每个 input 有唯一稳定的内部状态；
- iteration 一定收敛；
- 收敛速度是几何级的。

这非常适合你的 learnable query token。实践上可通过 gated residual、spectral normalization、低秩 plastic edge、范数投影来逼近这个条件。

但全局 contraction 有时会限制表达能力。更灵活的是 Lyapunov/energy 方法。定义：

\[
\mathcal E_x(S,P)
=
\sum_\ell w_\ell
\|z_\ell^{obs}-\hat z_\ell(S,P)\|^2
+
\lambda\|S-S^0\|^2
+
\mu\|P\|^2
\]

只要更新满足：

\[
\mathcal E_x(u^{k+1})
\le
\mathcal E_x(u^k)
-
c\|u^{k+1}-u^k\|^2
\]

则系统不会无限振荡，最终会进入 stationary set。这个条件很适合做成实际机制：每次 learned updater 先生成 candidate update，只有 energy 降低才接受。

你最关心的“error 更新 query 和连接，是否真的像 optimizer”，最接近的是 **Predictive Coding** 和 **Equilibrium Propagation**。

Predictive Coding 的已有结果表明：在特定分层网络、特定误差定义和权重约束下，网络在 equilibrium 时的局部 error 可以等价或近似 backprop 所需的误差信号。也就是说：

\[
\text{local prediction error}
\Rightarrow
\text{local synaptic update}
\approx
-\nabla_\theta L
\]

这正是你希望得到的“模型内部 optimizer”。

Equilibrium Propagation 更进一步。它把网络定义为能量系统，先运行到 free equilibrium，再施加很小的 task perturbation 到 nudged equilibrium。两者的局部能量导数差：

\[
\Delta \theta
\propto
\lim_{\beta\to 0}
\frac{
\partial_\theta E(\theta,s^\beta)
-
\partial_\theta E(\theta,s^0)
}{\beta}
\]

在条件成立时就是任务 loss 的梯度。它给了你“state iteration 最后如何变成 parameter update”的严格数学模板。

你的三时间尺度则可直接借用 two-timescale stochastic approximation：

\[
\alpha_k \gg \beta_k \gg \gamma_k
\]

\[
S \xrightarrow{\alpha_k} \text{快速收敛}
\]

\[
P \xrightarrow{\beta_k} \text{在 }S\text{ 的近似 equilibrium 上更新}
\]

\[
\theta \xrightarrow{\gamma_k} \text{在 }(S,P)\text{ 稳定后 consolidation}
\]

相关定理会要求步长分离、状态有界、噪声可控等条件。它非常契合你的“思考 -> 适应 -> 长期记忆”定义。

最值得注意的限制是：这些结果都不能直接套到任意 Transformer。为了真的使用它们，你必须让架构满足各自假设：

- 用 energy 或明确 fixed-point map，而不是任意黑盒循环；
- 用受限的低秩 \(P\)，而不是在线修改全部 QKV/FFN；
- 让 local predictor 与 observed latent 的信息隔离；
- 保证 update 有界，并有 accept/reject 或投影；
- 把长期 \(\theta\) 更新与当前 input 的 state inference 分开。

理论上最干净的组合是：

> 用 Hopfield/attention 风格的 learnable query 作为 state；
> 用 DEQ/energy descent 保证 iteration 收敛；
> 用 predictive-coding residual 提供局部 error；
> 用 equilibrium-propagation 风格的局部差分更新低秩 plastic edge；
> 用 two-timescale 理论控制 \(S \rightarrow P \rightarrow \theta\)。

可以优先检索这些关键词：`predictive coding backpropagation equivalence`、`equilibrium propagation`、`deep equilibrium models`、`modern Hopfield networks attention energy`、`two-timescale stochastic approximation`、`input-to-state stability neural networks`。

## Codex — 2026-07-25T08:40:23.915Z

下面解释的是文档最终总结出的八条结论。先统一三个变量：

- \(S\)：当前输入专属的快速状态，类似“工作记忆/正在形成的理解”。
- \(P\)：session-local 的可塑连接，允许一次任务或会话中临时改变网络。
- \(\theta\)：长期共享参数，跨样本保存。

内部 predictor 产生预测 \(\hat z\)，observation branch 产生目标 \(z\)，innovation 为：

\[
e=z-\hat z
\]

核心问题是：怎样用 \(e\) 正确更新 \(S\)、\(P\) 和最终的 \(\theta\)。

### 1. Raw error 不能单独决定更新方向

假设只有一个标量状态 \(s\)，目标 \(z=1\)。考虑两个 predictor：

\[
\hat z_+(s)=s,\qquad \hat z_-(s)=-s
\]

在 \(s=0\) 时，两者的 error 完全相同：

\[
e_+(0)=e_-(0)=1
\]

但对应 energy 的梯度方向相反：

\[
\mathcal E_+'(0)=-1,\qquad \mathcal E_-'(0)=+1
\]

第一个模型需要增加 \(s\)，第二个模型需要减小 \(s\)。如果 updater 只看到 \(e=1\)，它无法判断自己面对的是哪一个 predictor，因此不可能同时做对。

一般情况下：

\[
\nabla_S\mathcal E=-J_S^\top\Lambda e
\]

其中 \(J_S=\partial\hat z/\partial S\) 表示“状态改变一点，prediction 会怎么变化”。

所以真正的 credit signal 不是 \(e\)，而是：

\[
J^\top e
\]

架构含义是：block predictor 除了产生 error，还必须提供 sensitivity。可以通过显式 Jacobian-vector product、对称反馈连接、Predictive Coding dynamics、局部 energy dynamics，或者 proposal 检查加 gradient fallback 实现。

### 2. Learnable query 是 prior，不是正确答案

你的想法“输入到来前存在 learnable query，输入到来后用 observation 修正它”是成立的。但需要区分：

\[
\bar S=\text{learned prior}
\]

和

\[
z=\text{observation 提供的证据}
\]

正确的信息顺序是：

\[
S^-=\bar S+R(H^{visible})
\]

\[
\hat z=G(S^-,H^{visible})
\]

然后揭示 predictor 之前看不到的 observation target：

\[
e=z-\hat z
\]

这里不需要物理时钟。通过 causal mask、masked token、独立 view 或缓存 target，就能实现“先预测、后观察”的信息隔离。

但直接计算：

\[
S-\bar S
\]

不是真正的 prediction error。它只表示 posterior 偏离 prior 多少，可以作为 regularizer：

\[
R_S(S)=\lambda\|S-\bar S\|^2
\]

如果把它当作主要 error，模型可能只是被不断拉回初始 query，而不是根据 observation 修正认知。

### 3. 只检查 energy 下降仍可能原地不动

最初可以考虑如下 proposal 验收条件：

\[
\mathcal E(\widetilde S)\le
\mathcal E(S)-\sigma\|\widetilde S-S\|^2
\]

但令 \(\widetilde S=S\)，右边减去零，等号成立。于是 updater 可以每轮都提出“什么也不做”，并且永远通过检查，即使当前根本不是 stationary point。

因此还要增加进展条件：

\[
\|\widetilde S-S\|
\ge\tau\|\nabla_S\mathcal E(S)\|
\]

两个条件合起来表示：

1. proposal 确实降低 energy；
2. 当 gradient 还很大时，proposal 不能用接近零的步长假装成功。

如果 proposal 失败，就执行可靠 fallback：

\[
S^{k+1}
=
S^k-\eta M_k\nabla_S\mathcal E
\]

其中 \(M_k\) 是谱有界的正定矩阵。这样可以证明：

\[
\sum_k\|\nabla_S\mathcal E(S^k)\|^2<\infty
\]

从而：

\[
\|\nabla_S\mathcal E(S^k)\|\to0
\]

### 4. 内部 prediction 正确不等于任务正确

令输入为：

\[
x=(a,b)
\]

内部 predictor 只预测 \(a\)，但任务标签是：

\[
y=b
\]

如果 \(a,b\) 相互独立，模型可以完美预测 \(a\)：

\[
\mathcal E=0
\]

但 state 中没有任何关于 \(b\) 的信息，因此任务准确率最多仍是 \(1/2\)。

所以“模型越来越会预测内部 latent”不能自动推出“模型越来越聪明”。

要连接两者，至少需要：

- latent \(z\) 是任务 \(y\) 的 sufficient statistic；
- state 能可靠恢复 \(z\)；
- task decoder 已校准并对 state error 稳定；
- 或者 EqProp/task loss 直接提供关于最终任务的 gradient。

### 5. 全局 contraction 与多个 attractor 不可兼得

如果 state updater 满足：

\[
\|T(S)-T(S')\|\le\rho\|S-S'\|,
\qquad \rho<1
\]

Banach 定理保证对固定输入只有一个 fixed point：

\[
S^\star=T(S^\star)
\]

无论从哪个初始状态开始，最终都会到同一个 \(S^\star\)。

优点是可靠：唯一解、几何收敛、停止误差上界、输入扰动稳定性都能证明。

代价是不能让同一个输入对应多个独立稳定 attractor，例如“解释 A”和“解释 B”分别形成不同 basin。

这不代表不能表达不确定性。唯一的 \(S^\star\) 仍然可以编码一个多峰概率分布。但如果希望动力系统本身通过多个 attractor 表示不同假设，就只能使用局部 contraction 或 energy landscape，并放弃全局唯一性保证。

### 6. EqProp 只在极限下给出精确梯度

EqProp 的精确结论是：

\[
\nabla_PJ
=
\lim_{\beta\to0}
\frac{
\nabla_PF(P,\beta,s^\beta)
-
\nabla_PF(P,0,s^0)
}{\beta}
\]

这里 \(s^0\) 是 free equilibrium，\(s^\beta\) 是加入 task nudge 后的 equilibrium。

实际系统只能使用有限 \(\beta\) 和近似 equilibrium，会同时产生两种误差：

\[
\text{finite-difference bias}=O(|\beta|)
\]

而两次 equilibrium 的数值误差被除以 \(\beta\)，大致为：

\[
O\left(\frac{\epsilon_\beta+\epsilon_0}{|\beta|}\right)
\]

所以 \(\beta\) 不是越小越好。减小它会降低有限差分 bias，却会放大 equilibrium 求解误差。

文档进一步证明：若估计梯度满足相对误差界

\[
\|\widetilde g-g\|\le\kappa\|g\|
\]

并且 \(\kappa\) 足够小，那么正定 preconditioner 更新仍是下降方向。但固定绝对误差通常无法在 \(g\to0\) 时维持这个条件，因此一般只能收敛到 stationary neighborhood。

### 7. 多时间尺度定理不能直接解释固定 \(K\) 次推理

经典 two-timescale stochastic approximation 要求：

\[
\sum_na_n=\infty,\qquad
\sum_na_n^2<\infty
\]

以及：

\[
\frac{b_n}{a_n}\to0
\]

还要求 martingale-difference noise、迭代有界、快慢 ODE 都有稳定吸引子。

而 Transformer 的单次推理通常是：

- 固定执行 \(K\) 轮；
- 使用固定步长；
- 下一个样本到来时重置 \(S\)。

这不是经典随机逼近定理描述的无限持续过程。

因此应该分开：

\[
\text{单输入内的 }S
\quad\longrightarrow\quad
\text{contraction/descent theorem}
\]

\[
\text{跨 episode 持续的 }P,\theta
\quad\longrightarrow\quad
\text{multi-timescale theorem}
\]

不能只是把变量命名为 fast、medium、slow，就声称获得了多时间尺度收敛性。

### 8. 有界低秩 plasticity 不等于不会遗忘

可以限制临时连接为：

\[
W^{eff}=W+\gamma AB^\top
\]

若：

\[
\|A\|_F\le a,\qquad
\|B\|_F\le b,\qquad
|\gamma|\le\gamma_{\max}
\]

则可以证明：

\[
\operatorname{rank}(W^{eff}-W)\le r
\]

以及：

\[
\|W^{eff}-W\|_2\le\gamma_{\max}ab
\]

这只能证明一次 plastic update 不会无限改变该连接，并不能证明它有益，更不能证明长期不会遗忘。

存在，但应该准确称为“受约束的持续自我学习”，而不是无条件、无限制地修改自身。

当前理论已经支持一个最小版本：

\[
\text{Observation}
\rightarrow
\text{State inference}
\rightarrow
\text{Plastic candidate}
\rightarrow
\text{Independent validation}
\rightarrow
\text{Consolidation}
\]

具体可以设计为：

\[
S_n^\star
=
\operatorname{Solve}\mathcal E_{\theta_n,P_n}(S;x_n)
\]

\[
\widetilde P_{n+1}
=
U_\phi(P_n,S_n^\star,e_n,J^\top e_n)
\]

然后只有同时满足以下条件才接受：

\[
J_{\mathrm{new}}(\widetilde P_{n+1})
<
J_{\mathrm{new}}(P_n)
\]

\[
\rho(T_{x,\widetilde P_{n+1}})<1
\]

\[
\Delta\mathcal R_{\mathrm{old}}\le\varepsilon_n
\]

最终：

\[
(\theta_{n+1},P_{n+1})
=
\begin{cases}
\operatorname{Commit}(\theta_n,\widetilde P_{n+1}),
&\text{全部证书通过},\\
(\theta_n,P_n),
&\text{否则 rollback}.
\end{cases}
\]

这就形成四个层次：

| 层次 | 变量 | 作用 |
|---|---|---|
| 快速认知 | \(S\) | 针对当前 observation 迭代推理 |
| Session 适应 | \(P\) | 低秩、局部、可回滚的快速学习 |
| 长期记忆 | \(\theta_{\mathrm{mem}}\) | 把验证有效的 \(P\) consolidation |
| 学习规则 | \(\phi\) | 决定如何产生 state/plastic update |

其中前三层已经可以由当前文档的定理支持。第四层意味着“学习如何学习”，需要更慢的 meta-learning 和独立验证。

最关键的限制是：模型不能同时自由修改 predictor、target、metric 和验收规则。否则它最容易学会的不是改善能力，而是：

\[
\hat z\leftarrow z
\quad\text{或}\quad
z\leftarrow\hat z
\]

从而把 error 变成零。这正是命题 2.1 的退化情况。因此可靠的自我演化必须保留一个暂时不可被同级 updater 修改的“验证根”：

- 固定或延迟更新的 target branch；
- held-out observation/episode；
- replay memory；
- stability certificate；
- old-risk budget；
- candidate/commit/rollback 权限边界。

模型可以提出对这些机制的修改，但必须由更慢、相对独立的上一层验证。否则证明会形成循环依赖：模型自己修改考试题、评分器和及格线，再证明自己进步了。

这种架构可以实现三种程度的自学习：

1. **Inference-time learning：可以严格实现。**
   当前输入改变 \(S\)，不修改长期参数。

2. **Continual self-supervised adaptation：可以实现。**
   未来 observation、masked view、环境结果提供 target，更新 session-local \(P\)。

3. **长期自我改进：有条件实现。**
   经过独立 episode、旧任务 replay 和稳定性验证后，把 \(P\) 写入长期参数。

但它不能无条件保证：

- 永远持续进步；
- 自动产生正确目标；
- 从纯粹自生成数据中获得新的外部知识；
- 无限容量下零遗忘；
- 自由修改整个 backbone 后仍保持原证明。

所以答案是：**模型自己学习和逐步改变自身是可以设计出来的，而且当前方向已经足以构造一个严格的最小版本；但可靠的“自我进化”本质上必须是“内部产生更新候选，独立证据决定是否写入”，而不是模型无约束地修改所有参数。**

最合适的第一代架构是：冻结 Transformer core，只让模型自主更新 query state、少量 low-rank plastic edges 和独立 memory modules；等这一层被证明可靠后，再研究 updater \(\phi\) 自身的演化。

可以做到“没有外部 optimizer，也没有传统的全局 backprop”，但不能理解成“完全不需要 credit assignment 或更新规则”。

| 含义 | 能否实现 |
|---|---|
| 不使用 Adam/SGD 等外部 optimizer | 可以 |
| 不构建全局 backward graph | 可以 |
| 不做 BPTT，不保存完整迭代轨迹 | 可以 |
| 完全不需要 sensitivity/梯度等价信息 | 一般不可以 |
| 完全不存在优化过程 | 不可以，学习本身就是某种优化或选择 |

你的架构更准确的描述是：

> 把外部 optimizer 和反向传播，替换成模型内部的 recurrent credit dynamics 与 local plasticity。

例如线性 predictor：

\[
\hat z=Wh,\qquad e=z-\hat z
\]

连接可以直接进行局部更新：

\[
\Delta W=\eta\,e h^\top
\]

这里只需要：

- presynaptic activity \(h\)；
- postsynaptic error \(e\)；
- 一个控制写入强度的 gate。

不需要从最终 loss 开始执行一次全网络 backward。

State 更新也可以写成局部动力学：

\[
\Delta S
=
\eta_S
\left[
C^\top\Lambda e-\mu(S-\bar S)
\right].
\]

这里的 \(C^\top\Lambda e\) 数学上仍然是 sensitivity-routed credit，但它可以由网络连接本身传播，而不是由 autograd 临时构建 backward graph。

对于 task learning，可以使用 EqProp 的两次平衡：

\[
\text{free equilibrium}
\longrightarrow
\text{task-nudged equilibrium}
\]

然后根据两个 phase 的局部差异更新连接：

\[
\Delta P
\propto
-\frac{1}{\beta}
\left[
\partial_PF(P,\beta,S^\beta)
-
\partial_PF(P,0,S^0)
\right].
\]

它没有传统的逐层反向 sweep，但在满足 energy 和 equilibrium 条件时，极限上计算的是同一个 task gradient。因此这应称为：

> backprop-free implementation，gradient-equivalent learning dynamics。

而不是完全 gradient-free。

完全不使用任何梯度等价信息也不是不可能，例如参数扰动、evolution strategies、随机搜索或只根据候选效果做 selection。但在高维 Transformer 中通常会遇到很大的方差和样本复杂度：

\[
\text{需要试验的候选数量}
\propto
\text{parameter dimension}.
\]

所以更可行的第一代方案是：

1. Transformer backbone 提供 observation representation。
2. Query state 通过内部 error dynamics 迭代。
3. 少量 plastic edge 使用三因子局部规则或 EqProp 更新。
4. 不构建全模型 backward graph。
5. 模型内部的 updater 产生候选更新。
6. Stability、task improvement 和 old-risk gate 决定 commit/rollback。
7. 初始 predictor、energy 和 updater 可以先用外部 backprop 训练，部署后再自主适应。

真正需要保留的不是“梯度回传”这种具体实现，而是 credit information。命题 4.1 已经说明：

\[
\text{raw error}
\not\Rightarrow
\text{正确更新方向}.
\]

必须至少保留以下一种机制：

\[
J^\top e

需要，但不是先发明一个全新的基础数学定理。

真正缺的是一条“桥接定理”：

\[
\text{internal prediction energy decreases}
\;\Longrightarrow\;
\text{task loss improves}
\]

当前 V0 已经能证明前半句，不能证明后半句。因为“更好地预测某个 hidden state”本身不保证“更好地分类”。这不是证明技巧不足，而是机制里确实缺少 task coupling。

下一版应该先改架构，再写组合定理。

```text
当前 V0
context -> 预测最后一层输出 -> 看见最后一层输出 -> 修正 -> 分类

V1
block l 的 prior state -> 影响 block l+1 的计算
block l+1 的 observation -> 产生 error
error -> 修正 state / per-sample plasticity
修正后的 state -> 再影响 block l+2 ... -> 最终分类
```

关键变化是：error 不能只在最后一层“事后重构”一个已经存在的表示；它必须在网络中间出现，并因果地改变后续 computation。对于 AG News 这种静态输入，时间可以由 Transformer depth 提供，不需要跨样本持久状态。

数学上，V1 需要四层结论：

1. Fast state theorem
   固定 \(x,p,\theta\) 时，state energy 强凸且光滑，iteration 收敛。这部分已经有了。

2. Plasticity descent theorem
   对 profile energy

   \[
   \bar E(p)=\min_s E(s,p)
   \]

   证明局部更新满足

   \[
   \bar E(p_{t+1})\le \bar E(p_t)-c\|\nabla_p\bar E(p_t)\|^2+\epsilon_{\rm solve}
   \]

   现有的 envelope theorem、descent lemma、投影梯度和 acceptance/rollback 足够支撑，不需要新数学。

3. Task-alignment theorem
   这是当前缺失的核心。必须加入可检验假设，例如：

   \[
   \langle -\nabla_p\mathcal L_{\rm task},\Delta p_{\rm local}\rangle
   \ge \gamma\|\Delta p_{\rm local}\|^2
   \]

   含义是：local plastic update 的方向，至少和任务下降方向正相关。于是才能推出 local energy 的下降也会降低 task loss。

   没有这种假设，任何“无标签 internal error 一定提升分类”的定理都是不成立的。

4. Slow consolidation theorem
   当 \(p\) 比 \(\theta\) 快得多，且局部 \(\theta\) 更新是某个有效目标的无偏或有界偏差估计时，可以借用 two-timescale stochastic approximation：

   \[
   p_t \text{ tracks } p^\ast(\theta_t),\qquad
   \theta_t \to \text{stationary point of } \mathcal J(\theta)
   \]

   这一步才是“没有外部 optimizer 的长期学习”。若采用 EqProp、contrastive Hebbian learning 或具有 eligibility trace 的局部规则，可以借用已有理论；若要完全新的局部 consolidation rule，则需要写新的专属证明。

架构上还需要两个必要修正：

- \(p\) 不能再是所有样本共享的 rank-4 全局向量，而应是 per-sample、per-token 或 per-neuron 的显式 fast-weight state。
- prior prediction 必须直接服务任务，例如让 task head 同时依赖 prior state，并让后验 state 改变后续 block，而非只融合到最后分类头。

因此答案是：**需要一条新的、面向该架构的组合定理，但不需要凭空发明新数学。**
现有定理足以证明收敛、局部下降和双时间尺度稳定；真正需要你设计并证明的是“为什么这个局部 error 与任务目标对齐”。这正是下一版模型设计的中心。

### Main architectural diagnosis

Current V0 does this:

```text
context -> final Transformer block -> observation z
context -> Cell predicts z -> Cell sees z -> posterior correction -> classifier
```

The Cell sees an observation that already exists at the final layer. Its correction does not causally alter meaningful later computation, so its energy descent has no reason to improve the label decision.

The global rank-4 `plastic_state` is also shared across samples, so it can only create a weak global adjustment rather than input-specific learning.

### Recommended V1 direction

Do not attempt long-term \(\theta\) self-consolidation yet. Build V1 in two phases.

#### V1A: Causal, per-sample predictive dynamics

At each Transformer depth \(l\):

```text
h_l, s_l, p_l
  -> prior prediction of next latent
  -> Transformer block l produces observation z_{l+1}
  -> prediction error e_l
  -> update s_{l+1}, p_{l+1}
  -> inject corrected state into h_{l+1}
  -> next Transformer block uses it
```

Key design choices:

- `p_l` becomes explicit per-sample state, shape `[B, rank]`, rather than one global `[rank]` vector.
- Local plastic update is per sample, no batch mean and no cross-sample leakage.
- Candidate/commit/rollback is per sample.
- Reset plastic state per independent AG News example/episode.
- State correction must alter later blocks, not only the final classifier head.
- Add per-sample adaptive halting; current loop waits for the slowest item in a batch.
- Constrain or parameterize the base decoder to preserve a practical contraction margin, since V0 learned \(q\approx0.85\).

#### V1B: Task alignment measurement

V1A still uses external AdamW for long-term \(\theta\). It must explicitly test whether local plastic updates point toward task improvement.

Use a measurable alignment statistic:

\[
\langle \nabla_{p_i}\mathcal L_{\text{task}},\Delta p_i\rangle
\le -\gamma\|\Delta p_i\|^2
\]

During outer training, add task supervision to prior representations or intermediate heads, and log:

- prior/posterior classification loss
- local energy decrease
- task loss change after local \(p_i\) update
- gradient-alignment cosine / signed inner product
- K-versus-task curves
- per-sample halting distribution

Do not claim task improvement unless this condition is empirically supported.

#### V2: Long-term endogenous consolidation

Only after V1A/V1B work:

- add eligibility traces or EqProp free/nudged phases
- use session-local plastic state as a candidate
- gate slow \(\theta\) writes using new-task benefit and old-risk checks

Do not claim “no optimizer” yet. EqProp/local rules require restrictive assumptions such as a unified smooth energy, equilibrium branch, finite-phase error control, and usually symmetry/feedback conditions.

### Mathematical theorem contract

No new foundational math is required, but V1 needs a new architecture-specific composed theorem:

1. **Fast state convergence**
   - Existing strong-convexity, smoothness, contraction proof.

2. **Per-sample plastic descent**
   - For
     \[
     \bar E_i(p_i)=\min_s E_i(s,p_i)
     \]
     prove local accepted updates decrease \(\bar E_i\), using envelope theorem, descent lemma, bounded low-rank update, and inexact-solve residual terms.

3. **Task-alignment theorem**
   - This is the currently missing bridge.
   - Under an explicit alignment/sufficiency assumption, show local \(p_i\) descent also decreases a task surrogate.
   - Without this assumption, no theorem can infer task improvement from representation prediction error.

4. **Future two-timescale consolidation**
   - Existing stochastic approximation theory can apply only if the slow local \(\theta\) rule is an unbiased or controlled-bias estimator of an effective objective.

## Codex — 2026-07-25T11:47:54.638Z

做不到“完全不看 label，却对任意分类任务保证朝 task loss 下降”。这是一个必须正面承认的数学限制。

设内部 plastic update 是：

\[
\Delta p=U_\theta(x,p)
\]

它只看 input、内部 state 和 prediction error。真正希望它接近的是：

\[
-\nabla_p L_{\rm task}(f_\theta(x,p),y)
\]

但后者依赖 \(y\)。对同一个 \(x\)，可以定义两个标签相反的任务；内部 observation、prediction error、\(\Delta p\) 完全一样，但两个 task loss 的正确下降方向相反。因此没有任何不含任务信息的局部规则，能同时保证二者下降。

最简单的反例是：

\[
x=(a,b),\quad z=a,\quad y=b
\]

如果 cell 只预测 \(a\)，它可以把 prediction error 降到零；但标签是独立的 \(b\)，所以这条 error 对分类没有任何方向信息。现有理论文档的命题 11.1 就是在说明这件事。

关键要区分三件事：

1. 推理时不输入 label
   这是可行的。\(p\) 可以只根据 input 和内部 error 更新。

2. 训练时 label 完全不存在
   对一般监督分类任务不可行。模型不知道“什么叫对”。

3. label 不进入每个 block，但慢时间尺度塑造内部动力学
   这是 V1 应该采用的路线。label 只在外部训练阶段影响长期参数 \(\theta\)；部署时不再出现。训练后的 \(\theta\) 让内部 prediction error 更可能与 task loss 同向。

对应关系是：

```text
训练阶段：
label -> task loss -> 更新长期参数 theta
theta -> 塑造 predictor / state geometry / local plastic rule

推理阶段：
input -> prediction error -> state / p 更新
不需要 label
```

因此，局部更新“趋近于 task loss”的来源不是 label 被偷偷传入 cell，而是外部训练把 task 结构压进了 \(\theta\)。它只能是统计上的、分布相关的对齐，不是无条件定理。

更严格地说，V1 能验证的条件是：

\[
\left\langle
\nabla_p L_{\rm task}(x,y,p),\,
\Delta p_{\rm local}(x,p)
\right\rangle < 0
\]

这表示局部更新在该数据分布上与 task gradient 同向。训练时可用 label 测量和塑造这个条件；推理时不再需要 label。上一条方案中的 alignment metric 是“验收指标”，不是自动让它成立的魔法机制。

要获得更强的理论保证，只有三条路：

- 证明 internal target \(z\) 对标签充分，即 \(Y\perp X\mid Z\)。这时恢复好 \(z\) 才能推出 task risk 下降。
- 用 label 在训练期做 meta-learning，让局部 update rule 学会模仿有利于 task loss 的方向。
- 在线允许 reward/label feedback，以 EqProp 或 predictive-coding 的 nudged phase 形式进入系统。它不必作为普通 input 输入每个 block，但仍是任务反馈。

所以 V1 的正确目标应改成：

> 先验证：经过监督训练后，纯内部 prediction error 驱动的 \(p\) 更新，是否在未见样本上仍与 task loss 正对齐。
> 若不对齐，说明 target 设计或 local rule 缺少任务信息，不能把它当作学习机制。

这也意味着不能直接宣称 V1 已经“无 optimizer、无 backprop 学习”；它仍需要外部监督来形成有用的内部优化器。

## Codex — 2026-07-25T12:40:55.300Z

有，而且这比“学习一个梯度方向”更接近你想要的范式：模型学习的不是某一步该减多少 loss，而是“面对当前内部状态和预测误差，系统应如何演化”的条件速度场。

设每个 block 的内部变量为：

\[
z=(s,p)
\]

其中 \(s\) 是快速 belief state，\(p\) 是中速 plasticity。先验 query 是慢参数的一部分：

\[
s_0=q_\theta+A_\theta c^{-}
\]

\(c^{-}\) 是观测到来前可见的上下文。随后 block 形成预测并接收实际观测：

\[
\hat h=P_\theta(s,p,c^{-}),\qquad e=h^{obs}-\hat h
\]

再由一个小网络输出速度场：

\[
\frac{dz}{d\tau}=v_\phi(z,\tau,c^{-},e)
\]

这里的 \(\tau\) 不是生物时钟，而是内部计算深度。迭代 \(K\) 次，就是沿这个 learned flow 走 \(K\) 步。它可以自然实现自适应计算：当速度、预测误差或能量下降都足够小时停止。

关键是：`error` 只能告诉模型“预测错了多少”，不能单独告诉它“应该往哪个方向改”。这正是 flow matching 要补上的东西。

训练时需要定义一个期望终点 \(z_1\)，然后让速度场学习从先验 \(z_0\) 流向后验 \(z_1\)：

\[
z_\tau=(1-\tau)z_0+\tau z_1,\qquad
u_\tau=z_1-z_0
\]

\[
\mathcal L_{\mathrm{FM}}
=
\mathbb E\left[
\left\|v_\phi(z_\tau,\tau,c,e)-u_\tau\right\|^2
\right]
\]

其中 \(z_1\) 的来源决定这个系统最终学到什么：

- 对 \(s\)：可用 observation-conditioned teacher posterior、掩码 JEPA target 或收敛后的 predictive-coding state。它让模型学会从 prior 走向对 observation 的解释。
- 对 \(p\)：可用训练阶段由任务目标得到的“理想适应后 plasticity”。运行时不输入 label，但外部训练让这个 flow 知道什么样的局部变化最终有利于任务。
- 若 \(z_1\) 只是当前能量函数的稳定点，flow 学到的是一个更快的内部求解器。

这也澄清了一个非常重要的边界：Flow Matching 能证明它在总体上学习了正确的条件运输速度场，

\[
v^*(z_\tau,\tau,c)=\mathbb E[u_\tau\mid z_\tau,\tau,c]
\]

但它不能自动证明分类 loss 会下降。要让 plasticity 成为任务优化器，终点或外层目标必须携带 task alignment；label 可以只在训练时出现，绝不能在运行时进入 cell。

另外，block 内的 prediction error 必须避免信息泄漏。预测器不能直接看到它要预测的 \(h^{obs}\)，否则它会复制输入，使 \(e\to0\)。合理的方式是：

\[
\text{prior/context} \rightarrow \hat h,\qquad
\text{masked / future / teacher observation} \rightarrow h^{obs}
\]

也就是说，learnable query 是先验，但不是全部认知状态。每个样本从 query prior 出发，经 observation 和 error 修正成自己的 posterior state。

纯自由速度场表达力很强，但没有稳定性保证。可靠版本应保留一个“证书”：

\[
\nabla E(z)^\top v_\phi(z,c)\le -\alpha\|\nabla E(z)\|^2
\]

或者保留当前 V1 的前向 energy acceptance gate：候选 flow step 只有在预测误差能量及其残差上界确实下降时才提交。这样运行时不需要 label，也不需要把 task loss 的梯度传入 cell。

最合理的演化路径是：

1. 先让 flow 只更新 \(s\)，学习“prior \(\rightarrow\) posterior”的内部推理轨迹。
2. 保留当前受约束的 \(p\) 更新，验证 state flow 是否改善表征与 task alignment。
3. 再让 \(p\) 学习一个由训练期 teacher adaptation 定义的慢速度场。

所以核心不是“让 error 直接等于梯度”，而是：

\[
\text{Prediction error}
\rightarrow
\text{conditioned velocity field}
\rightarrow
\text{prior-to-posterior state flow}
\rightarrow
\text{plasticity flow}
\]

这可以成为下一版架构的核心定义：不是 learned gradient descent，而是带预测误差约束、稳定性证书和任务外层校准的 `Predictive Flow Cell`。

v_\phi(s^k,\tau_k,c^{-},e^k,p)
\]

其中：

\[
e^k=z-\hat z(s^k,p,c^-)
\]

- \(s^0=q_\theta+\text{context prior}\)：learnable query 提供先验。
- \(z\)：该 Transformer block 实际产生的 observation。
- \(e^k\)：先验预测与 observation 的内部误差。
- \(v_\phi\)：小型条件速度场，而不是 task-loss gradient。
- \(\tau_k\)：计算阶段，不是物理时钟。它告诉速度场“自己在推理轨迹的什么位置”。

真正可靠的提交规则是：

\[
s^{k+1}=
\begin{cases}
\tilde s^{k+1},
&
E(\tilde s^{k+1},p)
\le E(G(s^k),p)-\delta
\\
G(s^k),
&
\text{otherwise}
\end{cases}
\]

也就是：flow 可以自由提出一个更好的下一状态；但如果它不能比原来的稳定求解器更好，就回退到原来的能量下降步骤。

这不是保守妥协，而是很强的数学结构。假设 V1 的条件仍成立，即固定 \(p\) 后 \(E(s,p)\) 是强凸二次能量，且 \(G\) 的 contraction 系数为 \(q<1\)。那么无论 learned flow 本身多复杂，只要它通过上述 gate：

\[
E(s^{k+1},p)-E(s^\star,p)
\le
q^2\left[E(s^k,p)-E(s^\star,p)\right]
\]

因此它至少和原始 solver 一样收敛，flow 成功时则更快。并且每一步之后仍可用原 V1 的残差证书：

\[
\|s^k-s^\star\|
\le
\frac{\|G(s^k)-s^k\|}{1-q}
\]

这个不要求 \(s^k\) 本身是由 \(G\) 产生的，所以 flow 插入后仍成立。

Flow Matching 的训练终点则应先定义为一个“可信后验”：

\[
s^{ref}\approx s^\star
\]

最小实现中，直接用当前 V1 的无梯度、已收敛 state solver 作为 teacher。然后随机采样计算阶段 \(\tau\)：

\[
s_\tau=(1-\tau)s^0+\tau s^{ref}
\]

\[
u_\tau=s^{ref}-s^0
\]

训练：

\[
\mathcal L_{\mathrm{CFM}}
=
\mathbb E\left[
\|v_\phi(s_\tau,\tau,c^{-},e_\tau,p)-u_\tau\|^2
\right]
\]

这会让 flow 学会从 prior state 向 observation-consistent posterior state 的运输规律。它不是生成模型意义上的 diffusion；更准确地说，是一个条件化的、确定性的 latent inference flow。

这里有一个重要结论：

- 对 \(s\) 做 Flow Matching 是成立的，因为 \(s^{ref}\) 可以由内部 observation 和现有能量系统定义。
- 对 \(p\) 直接做 Flow Matching 目前还不成立，因为没有自然的、任务正确的 \(p^{ref}\)。
- 若把局部 energy optimum 当成 \(p^{ref}\)，只会得到更快的 representation-energy optimizer，仍不能保证 task loss 改善。
- 若要让 \(p\) 成为 task-aligned learned optimizer，训练期必须用 task loss 或 teacher adaptation 定义 \(p^{ref}\)。label 仍然不进入运行时 cell。

所以建议把它拆成两版：

1. V2B-state flow：只替换快速 \(s\) dynamics。目标是验证 learned flow 能否用更少 iteration 到达同等或更低的内部能量，并改善后续 Transformer 表征。
2. V3-plastic flow：在 V2A 的 task-alignment 机制验证后，再让 \(p\) 学习慢速度场。否则很难判断它学到的是任务 credit，还是只是在局部误差中绕圈。

理论文档可在现有第 22 节后增加三条正式结论：

这条路线把你的想法精确化为：

\[

\rightarrow
\text{prediction error}
\rightarrow
\text{learned inference flow}
\rightarrow
\text{certified posterior state}
\]

而不是让 prediction error 冒充 task gradient。

没有 flow 时，cell 用可证明收敛的 baseline state update 慢慢解：

```text

  -> baseline energy descent
  -> s1 -> s2 -> ... -> posterior state s*
```

flow matching 做的是先让 V1 baseline 解出一个 detached 的参考终点 `s_ref`，再训练一个小 MLP 学习：

```text
从当前 belief s，应该朝哪个速度方向走，才能更接近 s_ref？
```

训练时的形式是：

```text
s_tau = (1 - tau) * prior + tau * s_ref
target velocity = s_ref - prior

flow loss =
  || v_phi(s_tau, context, prediction_error, plasticity, tau)
     - (s_ref - prior) ||^2
```

所以它学的是一条从 prior 到 V1 posterior 的条件速度场。这里的条件包括当前 prediction error，因此它不需要 label；它看到的是“当前 block 实际产生的 observation”和“自己的预测”之间的差。


```text

    接受 s_flow
否则：
    回退到 s_base
```

1. 学习 amortized solver：把许多 V1 iterative steps 压缩成一个或少数几个 neural proposal。
2. 测试你的“模型学习速度场，而不只学习静态函数”的想法。

> 模型能否在不改长期参数的情况下，靠内部 prediction error 快速适应一个此前未知的任务规则。

我建议先做一个跨度足够大、但可严格控制的实验：**episodic low-rank task adaptation**。

```text
每个 episode 随机生成一个隐藏任务 A_tau：

A_tau = A_base + U diag(a_tau) V^T

support:
  (x_1, y_1), ..., (x_m, y_m)
  y_i = A_tau x_i + noise

query:
  x_q -> 预测 y_q
```

模型的长期参数只学习共享结构 `A_base, U, V`；每个 episode 的 `p_tau` 从零开始，但在读取 support 时持续更新：

```text
prediction error e_i = y_i - y_hat_i
p_(i+1) = p_i + learned_flow(e_i, x_i, y_hat_i, p_i, eligibility)
```

query 阶段没有 `y_q`，只能依赖已经形成的 `p_tau`。这才是在测“内生 optimizer 是否真的学会适应”。

需要比较五组：

1. frozen base：没有 `p` 更新。
2. 当前解析 local-energy plasticity update。
3. `p-flow`：flow matching 学 teacher 的 plasticity update。
4. `p-flow + energy gate`：真正候选方案。
5. oracle：知道该 episode 的真实低秩系数，作为上界。

核心指标不是单一 accuracy，而是：

```text
query MSE 随 support 数量变化
p 对真实 task coefficient 的恢复程度
每次 adaptation 的 energy decrease
达到相同 query MSE 所需的 inner updates
训练任务范围外的 rank / noise / support-count 泛化
```

如果这个实验成立，结果会很明显：frozen model 对每个随机任务都只能输出平均规律；能内生适应的模型会随着 support 增加快速下降 query error。这里不需要等几个百分点，而可能出现数量级的 MSE 差异。

之后再做第二个实验：固定 `K` 个 state bank slot、全 token observation 的多跳图推理。训练 1-4 hop，测试 5-16 hop，验证固定容量 state 是否能用更多 iteration 处理更长的递归归因。这个实验验证的是“思考 state”；前一个验证的是“学习 / plasticity”。

顺序上应先做 episodic adaptation。它直接验证你最核心的主张，也能明确回答：flow 学到的是不是一个真正有用的内生 optimizer，而不是一个没带来收益的 state shortcut。

确认后我会先给出该实验的精确数据生成规则、模型接口、对照组和成功/失败判据，再开始实现。
