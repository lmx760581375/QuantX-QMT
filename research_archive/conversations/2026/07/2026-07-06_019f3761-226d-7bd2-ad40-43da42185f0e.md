超级趋势Supertrend具有非常好的趋势跟踪性，策略基于真实波幅(ATR)的超级趋势交易系统，通过动态计算上下轨道来判断市场趋势方向，并结合严格的止损和资金管理规则进行交易决策。系统包含趋势判断、开平仓信号、止损机制和资金管理四个核心模块。
策略核心思想
超级趋势交易策略(SuperTrend)是一种基于波动率调整的趋势跟踪系统，它通过动态计算价格通道来判断市场趋势方向，并据此进行交易决策。
这个超级趋势交易策略是一个完整的系统化交易方案，从趋势判断到风险管理都有明确规则,自适应市场波动,在强趋势行情中能获得丰厚收益,不预测反转,可应用于股票、期货、外汇等多个市场
策略原理：
1.计算平均真实波幅
2.构建价格通道
中价 = (最高+最低)/2
上轨UP = 中价 + M×平均真实波幅
下轨DN= 中价 - M×平均真实波幅
3.生成超级趋势线
L1：最近一次上轨下降时的上轨值
L2：上轨的N×1.5周期最低值
LL：趋势线值（关键判断）LL 是在特定趋势转折点下选择的一个代表趋势状态的参考线，用于后续判断趋势方向。
当L2变化且L1下降时取L1
当L1=L2时取L1，其他情况取L2
2. 趋势信号
S1 ，记录上次上轨和超级趋势线相等位置
S2 ，统计在 S1 周期内，价格是否上穿超级趋势线 或 前两根的 LL，且此时 上轨 > 超级趋势线；一旦满足某种条件，触发 S2。
A6，最近一次S2条件满足的K线位置
B6，最近一次价格上穿DN的最高值的K线位置
BY，判断B6是否上穿A6
SL，判断A6是否上穿B6
上升趋势(B6>A6)：取DN的最高值连线
下降趋势(B6<A6)：取UP的最低值连线
IF 上升趋势 THEN
超级趋势线 = 下轨的最高值连线
ELSE
超级趋势线 = 上轨的最低值连线
END IF
买入信号
价格自下向上突破超级趋势线
超级趋势线由下降转为上升
当前趋势状态为"上升趋势"
卖出信号：
价格自上向下跌破超级趋势线
超级趋势线由上升转为下降
当前趋势状态为"下降趋势"
1. 初始止损规则
止损价 = 开仓价 - Z×ATR   （多头）
止损价 = 开仓价 + Z×ATR   （空头）
2. 移动止损规则
盈利超过X%时，止损价 = 最高价 - Y%×(最高价-开仓价)
盈利超过X%时，止损价 = 最低价 + Y%×(开仓价-最低价)
