## 一、先把研究问题拆成三层

### 1. 条件 Alpha 是否真实存在

先不要训练模型，只验证：

```text
事件日 D：股票首次涨停
买入日 D+1：按开盘价买入，要求开盘可成交
卖出日 D+2：按收盘价卖出
```

计算 D+1 开盘到 D+2 收盘收益：

$$
r_{i,D}=\frac{C_{i,D+2}}{O_{i,D+1}}-1
$$

比较：

- 首板事件池的收益分布；
- 同期全市场收益分布；
- 同行业、同市值、同日匹配对照组；
- 首板池内部不同特征组的收益差异。

这一层回答的是“首板条件下有没有 H2 Alpha”，避免模型从市场风格或时间段中“变出”Alpha。

### 2. Alpha 是否可在 D 收盘时预测

标签可以使用 D+1、D+2 的未来价格，但模型输入必须严格截止 D 收盘。

例如：

```text
feature cutoff = D 收盘及以前
entry = D+1 开盘
exit = D+2 收盘
```

如果把 D+1 开盘是否涨停直接用于 D 收盘选股，就是未来信息。它只能：

- 用作不可成交过滤；
- 或把决策时点改成 D+1 开盘后，再使用当时可观测信息。

因此建议区分两个实验：

- `close_decision`：D 收盘选股，无法预知次日开盘状态；
- `open_decision`：D+1 集合竞价/开盘时二次过滤，然后成交。

### 3. Reward model 能否选出 good case

只有前两层成立，才进入 pairwise/ranking 模型。否则即使训练指标很好，也很可能只是类别失衡或时间泄漏。

## 二、事件池定义

建议 MVP 聚焦“严格首板”，不要一开始加入连板、炸板、ST 等复杂实体。

### 候选事件

股票在 D 日：

- 收盘价达到有效涨停价；
- D-1 未涨停；
- 最近可配置窗口内没有涨停，建议分别测试：
  - 一日首板；
  - 过去 5 日无涨停；
  - 过去 10 日无涨停；
- D 日正常交易；
- 排除 ST、退市整理、上市不足 N 日；
- 使用当日对应板块及制度的真实涨停比例；
- 复权数据用于特征，未复权价格和真实涨停价用于成交判断。

需要分开统计：

- 主板 10%；
- 创业板/科创板 20%；
- 北交所 30%；
- ST 特殊涨跌幅。

初期建议只做主板非 ST 10% 首板，减少制度混杂。

### 一字板与可交易性

至少标记：

- `open_limit_up_D1`
- `high_eq_low_D1`
- `one_word_limit_up_D1`
- `open_limit_down_D1`
- `suspended_D1`

D+1 开盘涨停并不必然完全买不到，但仅靠 OHLC 无法判断排队成交。保守回测应视为不可买入。

## 三、good/bad 标签不要只做单一二分类

你的 good case 可以定义成：

$$
r^{oc2}_{i,D}=\frac{C_{D+2}}{O_{D+1}}-1
$$

建议先保存连续收益，再派生多种标签。

### 主标签

```text
good:
  D+1 开盘可买
  且 D+1 开盘到 D+2 收盘收益 >= θ

bad:
  候选事件池内其余可买样本
```

阈值建议同时测试：

- `θ = 5%`
- `θ = 7%`
- `θ = 9%`
- D+2 触及涨停；
- D+2 收盘涨停。

“触及涨停”和“收盘涨停”应分开，因为交易价值完全不同。

### 更适合排序学习的标签

不要只把 +6% 和 -8% 都压成 0/1。建议保留：

```text
future_return_d2_close
future_max_return_d1_d2
d2_limit_touch
d2_limit_close
future_max_drawdown
tradable_entry
```

训练时优先做同日排序：

$$
P(i \succ j)=\sigma(s_i-s_j)
$$

其中 $i$ 是同一事件日的高收益首板，$j$ 是同日低收益首板。

这比“good 对全市场几千个 bad”更合理。因为如果 bad 包含大量非首板股票，模型最容易学到的是“识别首板”，而不是“在首板中选择次日可买且后日大涨的股票”。

## 四、负样本设计是关键

建议分三组实验：

### A. 首板池内排序

- 正样本：首板中未来高收益者；
- 负样本：同日首板中未来低收益者。

这是最重要的实验，直接回答能否挑出优质首板。

### B. 匹配困难负样本

对每个 good case 匹配：

- 同日；
- 同板块；
- 相近市值；
- 相近 D 日涨停形态；
- 相近成交额/换手率；
- 但未来收益差。

用于迫使模型学习更细的结构。

### C. 全市场负样本

只作为辅助任务或预训练，不作为主结论。否则数千个 easy negatives 会让 AUC 很漂亮，但 top-k 选首板能力未必有提升。

Pair 不需要穷举。每天对每个正样本抽取若干 hard negatives 即可，避免 pair 数量二次爆炸和日期样本权重失衡。

## 五、特征构建

输入严格只使用 D 收盘以前的信息。

首板事件可能有价值的日线特征：

- D 日开高低收位置；
- 是否一字涨停、T 字板、实体板；
- 首次封板近似信息——仅日线无法准确获得；
- 成交额、换手率、量比；
- 过去 5/10/20 日收益和波动；
- 距前高、突破幅度；
- 市值、流通市值；
- 前期涨停次数；
- 连续上涨天数；
- 板块当日涨停数量；
- 同行业当日强度；
- 全市场涨停家数、炸板率；
- 大盘风格与情绪状态。

这里恰好解释为什么你之前纯分钟或纯日线模型可能学不出：目标可能高度依赖“横截面相对状态”和“市场情绪”，而不只是单只股票的时间序列。

因此数据单位不应只是：

```text
单股票 × 历史 K 线
```

而更应该是：

```text
事件日市场截面 + 单股票历史 + 所属板块状态
```

输出：

- 每日首板数量；
- D+1 开盘可买率；

- 流通市值/换手率/成交额规则；
- Logistic Regression；
- LightGBM/LambdaRank；

- 实际组合收益及最大回撤。

## 1. 指标定义

不能简单定义成“涨幅排名前20%”，因为每天占比恒定。建议先并行测试三种强势股定义：

- 短线强势：相对昨收涨幅 ≥2%，且价格位于日内区间上部。
- 趋势强势：当前价格高于昨日 MA20，且 MA20 向上。
- 放量强势：涨幅为正、累计成交额高于过去20日同一时刻均值。

然后构造：

```text
equal_breadth(t)  = 强势股票数 / 当时可交易股票数
amount_breadth(t) = 强势股票成交额 / 全市场成交额
```

两者的差值也很重要：

- 数量占比高、成交额占比高：真正普遍强势。
- 数量占比低、成交额占比高：少数大票拉指数。
- 数量占比高、成交额占比低：小票情绪活跃。

## 2. 情绪 K 线

用5分钟频率生成强势股占比序列：

```text
Open  = 09:35 强势股占比
High  = 当日截至当前的最高占比
Low   = 当日截至当前的最低占比
Close = 当前时刻或收盘占比
```

衍生特征：

- 实体：`Close - Open`
- 振幅：`High - Low`
- 上影：`High - max(Open, Close)`
- 下影：`min(Open, Close) - Low`
- 30分钟斜率与加速度
- 强势状态平均持续时间
- 当日新进入/退出强势状态的股票数
- 强势股票覆盖行业数
- 指数收益与情绪 K 线的背离

可能有价值的形态包括：

- 低开高走：市场情绪修复。
- 高开低走、长上影：强势扩散失败。
- 高位窄幅：强势状态稳定。
- 指数上涨但强势股占比下降：少数权重股拉升。
- 指数横盘但强势股占比持续上升：潜在扩散行情。

这些只能作为假设，不能预先赋予交易含义。

## Codex — 2026-09-28T08:42:09.342Z

当前实际用于软仓位实验的是“动量型市场温度”。

### 单只强势股定义

每5分钟判断一次。股票同时满足：

```text
过去48根5分钟K线收益 ≥ 3%
过去240根5分钟K线收益 ≥ 5%
当前有有效行情和成交
```

48根约等于1个交易日，240根约等于5个交易日。

### 市场温度

```text
市场温度 = 强势股票数量 ÷ 当前活跃股票数量
```

当前股票池覆盖沪深A股，包括主板、创业板和科创板；无成交或行情无效的股票不进入分母。

另外也计算了成交额温度：

```text
强势股成交额 ÷ 全市场活跃股票成交额
```

但本轮仓位控制只使用股票数量占比。

### 温度K线

每天48个五分钟温度点：

```text
开盘 = 09:35温度
最高 = 当日最高温度
最低 = 当日最低温度
收盘 = 15:00温度
实体 = 收盘温度 - 开盘温度
```

同时计算温度 MA5、MA10、MA20、振幅、上下影线和动量。

### 冷热阈值

阈值只用2010–2019年数据确定：

```text
冰点阈值：2.326%
高温阈值：6.860%
```

也就是：

- 收盘温度 ≤2.326%：冰点
- 2.326%～6.860%：中间状态
- 收盘温度 ≥6.860%：高温

再结合当天温度实体：

| 状态 | 判断 |
|---|---|
| 冰点继续下降 | 收盘≤2.326%，且收盘<开盘 |
| 冰点修复 | 收盘≤2.326%，且收盘≥开盘 |
| 中性 | 2.326%～6.860% |
| 高温扩散 | 收盘≥6.860%，且收盘≥开盘 |
| 高温回落 | 收盘≥6.860%，且收盘<开盘 |

### 仓位使用时点

严格使用：

```text
T日15:00温度状态
→ 控制T+1的新买单金额
```

不影响已有持仓，也不会触发强制卖出。

例如均衡版：

| 状态 | 次日新买单预算 |
|---|---:|
| 冰点继续下降 | 45% |
| 冰点修复 | 85% |
| 中性 | 85% |
| 高温扩散 | 100% |
| 高温回落 | 70% |

这里的45%是把原计划买入金额乘以0.45，不是把总持仓立即降到45%。
