```bash
HF_ENDPOINT=https://hf-mirror.com python your_script.py
```

- CLI 下载模型/数据集可断点续传：

```bash
HF_ENDPOINT=https://hf-mirror.com huggingface-cli download \
  --repo-type dataset \
  --resume-download \
  <repo_id> \
  --local-dir <target_dir>
```
