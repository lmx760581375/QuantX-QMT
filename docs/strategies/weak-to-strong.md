# 弱转强：规则策略合同

## 定位

弱转强是最终系统中的独立规则 sleeve，不依赖 Reward 模型。它选择主板中处于长期趋势、短期回落后重新转强、且流动性相对靠前的股票。

正式配置：[configs/strategies/weak_to_strong.yaml](../../configs/strategies/weak_to_strong.yaml)。

## 入场条件

策略使用 `all_mainboard`、60 日以上回看，按以下逻辑筛选：

1. **日内稳定性**
   - 绝对单日涨跌幅 `< 2%`；
   - 当日振幅 `< 7%`。
2. **BBI 趋势**
   - `BBI = (MA3 + MA6 + MA12 + MA24) / 4`；
   - `BBIUptrend(bbi, 2, 120, 0.20)` 必须成立。
3. **长短 RSV 结构**
   - 21 日 RSV 连续 5 日均不低于 75；
   - 5 日 RSV 先在高区，再在随后 1–4 日出现低区，当前重新回到高区；
   - 这是“强趋势中的短期弱转强”形态，而不是简单追涨。
4. **趋势确认**
   - `DIF = EMA12 - EMA26 > 0`；
   - `close > zxdkx` 且 `zxdq > zxdkx`；
   - `zxdkx = (MA14 + MA28 + MA57 + MA114) / 4`；
   - `zxdq = EMA(EMA(close,10),10)`。

候选按：

~~~math
score = liquidity\_rank + 0.01(rsv\_short-75)
      + 0.2\left(\frac{close}{zxdkx}-1\right)
~~~

排序，取前 4 个候选；组合最多持有 5 只。这一“Top4 候选、5 仓位”设置有意保留空位，避免为凑满仓位而买入低质量信号。

## 退出与仓位

| 规则 | 条件 | 操作 |
| --- | --- | --- |
| 分段减仓 | 浮盈 > 12%，且剩余仓位 > 初始仓位 85% | 减至 85%。 |
| 止盈 | 浮盈 > 21% | 全清。 |
| 止损 | 浮亏 < -8.9% | 全清。 |
| 弱早期失败 | 持有 >18 日、仍亏损、前 3/10 日回报恶化、历史峰值不足 2%、谷值低于 -7% | 全清。 |
| 移动退出 | 持有 >=5 日、峰值浮盈 >15%、自峰值回撤 <-10%，且不满足趋势豁免 | 全清。 |
| 趋势豁免 | `close > zxdq > zxdkx` 且长 RSV >45、短 RSV <25 | 不触发上述移动退出。 |
| 时间退出 | 持有 >25 日 | 全清。 |

成本与 Reward 对齐：佣金 5bp、最低 5、卖出印花税 1bp、滑点 10bp、close 成交。

## 冻结结果

2020-01-02 至 2026-06-02：

| 指标 | 值 |
| --- | ---: |
| 总收益 | 519.96% |
| 年化 | 32.87% |
| 最大回撤 | -33.99% |
| Sharpe | 1.004 |
| 平均持仓数 | 4.19 |
| 平均平仓持有日 | 26.06 |
| 成交数 | 793 |

它的关键限制是信号稀疏：平均仓位不足 5 是策略质量筛选的结果，不应为了提高资金利用率而强行扩大候选池。
