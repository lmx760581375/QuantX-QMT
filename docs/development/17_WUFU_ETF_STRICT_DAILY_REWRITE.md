# Wufu ETF Strict Daily Rewrite

本文记录五福 ETF 轮动从同日收盘成交改成严格日线交易模型后的实现和结果。结论先行：旧版 `same_close` 收益明显偏乐观；严格版保持正收益，但应以 `T+1` 结果作为后续比较基准。

## 1. 交易语义

严格日线版本遵守：

```text
T 日：用 T 日及之前的日线数据生成目标 ETF。
T+1：按配置在 T+1 开盘或 T+1 收盘执行换仓。
```

runner 新增参数：

```text
--execution-mode same_close | next_open | next_close
```

语义：

| execution_mode | 用途 | 是否作为主基准 |
|---|---|---|
| `same_close` | T 日收盘信号、T 日收盘成交，仅用于诊断旧版乐观结果 | 否 |
| `next_open` | T 日收盘信号、T+1 开盘成交 | 是 |
| `next_close` | T 日收盘信号、T+1 收盘成交 | 是 |

主可视化层已经从旧版同日成交 run 切换到严格版：

| 标题 | run_id |
|---|---|
| 五福ETF T+1开 | `20260708_100527_etf_wufu_next_open_confirm3_corr_daily_2016_2026` |
| 五福ETF T+1收 | `20260708_100530_etf_wufu_next_close_confirm3_corr_daily_2016_2026` |

## 2. 结果对比

配置均使用震荡期 3 日确认。

| 版本 | 总收益 | 年化 | 最大回撤 | Sharpe | 交易数 |
|---|---:|---:|---:|---:|---:|
| 旧版同日收盘成交 | `21.3317` | `34.37%` | `-23.29%` | `1.2315` | `1783` |
| 严格 T+1 开盘成交 | `12.1871` | `27.81%` | `-27.24%` | `0.9921` | `1779` |
| 严格 T+1 收盘成交 | `10.1473` | `25.78%` | `-26.69%` | `0.9136` | `1779` |

严格化后收益下降明显，说明五福日线复刻旧版确实吃到了同日收盘成交的乐观假设。但 `T+1` 两个版本仍然有较强收益，后续优化应以这两个版本为基线。

## 3. 时序校验

对两个严格 run 的 `trades.json` 做了逐笔校验：

| run | 检查交易数 | 非 T+1 成交数 |
|---|---:|---:|
| `next_open_confirm3` | `1779` | `0` |
| `next_close_confirm3` | `1779` | `0` |

校验方法：每笔交易的 `reason` 写入 `signal:YYYY-MM-DD`，再用 `selection_candidates.json` 的交易日序列反查该信号日的下一条选择日期，要求等于实际成交日。

## 4. 差距来源

同日版和严格版的 `selection_candidates.json` 在共同日期上目标 ETF 完全一致：

```text
common selection days: 2492
target mismatch: 0
```

因此差距不是选股逻辑变了，而是执行价从信号日收盘移动到了次日开盘或次日收盘。

按信号日收盘价到实际成交价拆分延迟影响：

| 严格版本 | 动作 | 平均价格移动 | 平均延迟影响 | 延迟有利比例 |
|---|---|---:|---:|---:|
| T+1 开 | 买入 | `+0.099%` | `-0.099%` | `41.39%` |
| T+1 开 | 卖出 | `+0.032%` | `+0.032%` | `39.23%` |
| T+1 收 | 买入 | `+0.218%` | `-0.218%` | `43.08%` |
| T+1 收 | 卖出 | `+0.133%` | `+0.133%` | `49.83%` |

含义：

1. 延迟买入平均会买贵，尤其 `T+1 收` 比 `T+1 开` 更明显。
2. 延迟卖出平均会卖贵，对结果有正贡献。
3. 买卖两边不是简单抵消，因为策略的仓位路径、复利基数和极端跳空会放大局部差异。
4. 2020、2022、2025 是旧版和严格版差距较大的年份；2024、2026 中 `T+1 开` 或 `T+1 收` 反而局部优于同日版。

## 5. 后续基准

后续 ETF 轮动改进应遵守：

1. 默认报告只展示 `next_open` 和 `next_close`。
2. `same_close` 只能作为诊断，用来估计执行延迟成本，不能作为实盘可比基准。
3. 新规则若提升收益，必须同时对比两个严格执行版本。
4. 若继续向五福原文靠近，应优先补齐日内成交、午盘成交额、NAV 溢价率等信息；没有这些信息前，不能把当前日线复刻结果等同于原 JoinQuant 策略。
